## 📌 Projetos em destaque

### 🏗️ Demos D'Gestão: ERP multiempresa
ERP para empresas de obras, serviços técnicos e atacado, com módulos de Financeiro, Comercial, Obras e Estoque.

- **Arquitetura multiempresa:** um banco PostgreSQL por empresa cliente, com a empresa resolvida a cada requisição e o mesmo schema para todos
- **Back-end:** .NET 10, ASP.NET Core, EF Core com migrations, Hangfire e OpenAPI
- **Segurança e rastreabilidade:** permissões em cada endpoint, refresh token rotativo, auditoria de dados financeiros e eventos em outbox
- **Front-end:** React, TypeScript, TanStack Router e Query, shadcn/ui e PWA pensado primeiro para o celular
- **Qualidade:** 198 testes com xUnit e Testcontainers (Postgres real), Vitest, Playwright e CI no GitHub Actions

🔒 Repositório privado (projeto próprio, em desenvolvimento)

### 📚 LIA: Livraria Inteligente Autônoma
Plataforma de livraria com loja, carrinho, checkout, ofertas de venda e solicitações de reforma, com IA em várias etapas do produto.

- **Visão computacional:** o Gemini avalia o estado dos livros por foto e orça reformas
- **Cadastro por foto:** a IA identifica o livro pela capa e preenche os dados no painel
- **Moderação e recomendações:** filtro de linguagem ofensiva e spoilers nas resenhas e recomendações via API do Skoob
- **Stack:** NestJS, Prisma e PostgreSQL, Angular 20, autenticação JWT, RBAC e pagamentos com Stripe

👉 [Back-end](https://github.com/octaviodemos/lia-back-end) · [Front-end](https://github.com/octaviodemos/lia-front-end)

### 📱 Compila: desafios de programação com IA
App mobile de desafios diários de programação em JavaScript e Python, com correção automática por IA.

- **Correção com IA:** respostas avaliadas pelo Google Gemini via Vercel AI SDK
- **Engajamento:** ranking semanal, sequência de dias, conquistas e notificações push
- **Stack:** React Native + Expo, Firebase Auth e Firestore, widget nativo Android em Kotlin e exportação do histórico em PDF

👉 [Repositório](https://github.com/octaviodemos/compila-app)
